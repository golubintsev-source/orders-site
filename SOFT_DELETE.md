# Мягкое удаление заказов

При нажатии «Удалить» заказы не удаляются из базы, а помечаются полем **deleted_at**. В списке «Все» показываются только заказы без пометки удаления.

## Колонка в таблице `orders`

| Поле         | Тип           | Описание |
|--------------|---------------|----------|
| **deleted_at** | `timestamptz` | NULL = заказ активен, дата/время = заказ удалён |

## SQL (Supabase → Table Editor или SQL Editor)

```sql
alter table orders
  add column if not exists deleted_at timestamptz default null;
```

После добавления колонки удаление в интерфейсе будет только проставлять `deleted_at`, строки останутся в базе.
