# Мягкое удаление задач

При нажатии «Удалить» в блоке «Я автор» / «Где я автор» задачи не удаляются из базы, а помечаются полем **deleted_at**. В списках показываются только задачи без пометки удаления. Удалять можно только свои задачи (автор).

Событие пишется в **task_history** и отображается на странице «Все изменения» (чип «Задача»).

## Колонка в таблице `order_tasks`

| Поле           | Тип             | Описание |
|----------------|-----------------|----------|
| **deleted_at** | `timestamptz`   | NULL = задача активна, дата/время = задача удалена |

## SQL

Выполните в Supabase SQL Editor:

1. `supabase_order_tasks_deleted_at.sql` — колонка `deleted_at` и защита «только автор»
2. `supabase_task_history_table.sql` — журнал удалений для «Все изменения»
